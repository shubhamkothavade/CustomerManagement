**Customer Management System**
A web-based application built using .NET Core MVC for managing customer records and fee tracking. 
The system allows full CRUD operations on customer data, including customer versioning to maintain historical changes. 
It also integrates a fee tracking feature, displaying total fees, fees paid, and pending fees for each customer, with an option to add and edit fee records.

Key Features:
Full CRUD functionality for customer management.
Versioning of customer records (master customer IDs) to track edits and updates.
Fee tracking system displaying Total Fees, Fees Paid, and Pending Fees.
Razor views for dynamic data entry and display.
Integrates with SQL Server to store and retrieve data efficiently.

Technologies:
ASP.NET Core, MVC, Entity Framework, SQL Server, JavaScript, HTML, CSS.
